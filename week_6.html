04 // Core Tactical Theory

The Cycle Counting Blueprint

Core Formula: Exponent÷Cycle Length=Remainder Position

1. Isolate Period Length: Find how many steps before the final digit repeats. Base 7 has a 4-step period: (7, 9, 3, 1).

2. Apply Remainder Rule: Exponent mod cycle length reveals exact step. Remainder 0 maps to the final step of the pattern.

05 // Advanced Theory

Modular Arithmetic Shortcuts

(a × b) mod n = [(a mod n) × (b mod n)] mod n

REDUCE FIRST: You can shrink huge bases and intermediate products by taking their remainders before multiplying.
EXPONENT PATTERNS: Focus only on the last digit when working with units digits—ignore all higher place values.
